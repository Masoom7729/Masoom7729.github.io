# Masoom — Developer Portfolio

A responsive dark-themed personal portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — page content and structure
- `style.css` — responsive styling and visual design
- `script.js` — mobile menu, scroll reveals and footer year
- `images/profile.jpg` — add your own profile photo here

## Add your profile photo
Create an `images` folder beside `index.html`, then add your photo with the exact filename `profile.jpg`.
A square, well-lit photo works best. If the photo is missing, the page displays an initial-based placeholder.

## Preview locally
Open `index.html` in a browser. For a better local workflow, use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Create a **public** repository named exactly `Masoom7729.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder (with `profile.jpg`).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment to finish. The site address is `https://Masoom7729.github.io/`.

## Customize before publishing
- Update the About section to describe yourself in your own words.
- Verify each project repository link and edit descriptions/tags to match the actual project.
- Replace the LinkedIn placeholder with your own LinkedIn profile URL, or remove that link.
- Add your profile photo at `images/profile.jpg`.

## Updating the site
Edit the files and commit/push the changes to the `main` branch. GitHub Pages will publish the update automatically.
